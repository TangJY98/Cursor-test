# Cursor-test

Hey, I'm **TangJY98** — welcome to my little sandbox.

This repo is where I poke at Cursor: try prompts, break things on purpose, and see what cloud agents can ship when I get out of their way. It's not a product. It's a lab bench with coffee stains and sticky notes.

## Why this exists

I wanted a quiet place to:

- experiment with Cursor Cloud Agents without worrying about production code
- practice writing clearer prompts (and laughing at the ones that go sideways)
- keep a running scratchpad of what works, what doesn't, and what surprises me

If you're reading this because an agent just opened a PR — hi. That was intentional. Or at least mostly intentional.

## What you'll find here

Probably not much polished code. Expect README tweaks, small experiments, and the occasional "wait, did that actually work?" commit. That's the point.
